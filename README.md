### Purpose

Given a start pose and a goal pose, the robot generates a trajectory and tracks it using PD control.

<img src="./project/image/robot2.png" width="500">

### Components

- MCU: ATmega128
- 12V motor + encoder + driver
- Gyro sensor
- Bluetooth communication module
